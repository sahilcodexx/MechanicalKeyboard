# KeyUI Component Library

An interactive, responsive React keyboard component library featuring Apple Magic Keyboard and Keychron K2 mechanical keyboard replicas with sound effects and haptic feedback.

## Features

- 🎹 **Apple Magic Keyboard & Keychron K2 Replicas**: High-fidelity geometry with authentic keycaps and active physical key press tracking.
- ⚡ **Instant Theme Switching**: Zero-latency light and dark mode toggling.
- 🔊 **Mechanical Switch Sound Effects**: Realistic scissor-switch and mechanical keypress audio feedback.
- 📱 **Web Haptics**: Native vibration feedback on supported touch devices.
- 📦 **CLI & Manual Installation**: Ready-to-copy components for your Next.js or React project.

## Usage

```tsx
import CustomKeyboard from "@/components/ui/custom-keyboard";

export default function App() {
  return <CustomKeyboard theme="dark" enableSound />;
}
```
